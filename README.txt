BIRTHDAY CARD TEMPLATE

1) Open index.html to test the page.
2) Edit data.js for the name, age, messages, photos, colors, music, and texts.
3) Put the music file at assets/music.mp3.
4) Put photos inside assets/photos/ and list their filenames in data.js.
5) For online hosting, upload the whole folder to GitHub and enable GitHub Pages, or drag the folder into Netlify.

Google Forms workflow:
- Create a Google Form with:
  * Name
  * Message for the birthday person
  * "Can your name appear?" (Yes/No)
- Share the form with the friends.
- Responses can be viewed in Google Sheets.
- Copy the final messages into the messages array in data.js.

IMPORTANT:
The example photos are intentionally not included. Replace photo1.jpg, photo2.jpg, etc. with your own files or remove them from data.js.
